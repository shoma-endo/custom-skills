# 比喩の領域を探す

「この商品は何をするか」から「世の中でほかに同じ働きをしているものは何か」へ考えを移す手順。

## 1. 機能を1文に縮める

「この商品は［誰］の［何］を［どうする］」。機能の列挙ではなく本質だけ。

- だめ: 「OCR・RPA・LLM を組み合わせて、発注書の読み取りと基幹システムへの転記を自動化し、運用まで支援する」
- よい: 「会社の面倒な手作業を、代わりに片付ける」

縮めた動詞が比喩の入口になる。「片付ける」→ 掃除・整理・番頭・庭の手入れ、のように広がる。

## 2. 6つの問い

1. **物の世界で、同じ働きをするものは？**（灯台は船を導く。関所は通るものを見張る）
2. **自然界では？**（蜂は巣を整える。川は流れを運ぶ）
3. **道具や機械では？**（ふるいは選り分ける。滑車は重い物を軽く持ち上げる）
4. **職業や役割では？**（番頭は店の切り盛りを任される。庭師は手入れを続ける）
5. **劇的な・極端な形では？**（炭鉱のカナリアは危険を先に知らせる）
6. **静かな・目立たない形では？**（根は地中で養分を運ぶ。黒子は舞台を支える）

## 3. 領域を地図にする

いきなり名前を出さず、関連する比喩のまとまり（領域）を並べる。有望な2〜3領域を選んでから名前を出す。

日本語の名前で使いやすい領域の例（出発点。これで全部ではない）:

| 領域 | 例 |
|---|---|
| 商家・職人 | 番頭、手代、女将、棟梁、杜氏、目利き、手習い |
| 道具 | 算盤、矩尺（かねじゃく）、鉋、砥石、風呂敷、暖簾、行灯 |
| 暮らし・家事 | 片付け、手入れ、下ごしらえ、繕い、仕込み |
| 自然 | 根、苗、水脈、追い風、潮目、灯 |
| 道・移動 | 道しるべ、渡し舟、橋、関所、宿場 |
| 舞台・芸能 | 黒子、裏方、拍子木、幕間 |
| 建築 | 礎、梁、足場、縁側、蔵 |

## 4. 掛け合わせる

機能をある領域から取り、絵を別の領域から借りると、ありきたりでない名前が出やすい。
例: 「業務の見張り」（監視）× 商家 → 「番頭」。監視の領域（見張り・警備）の中だけで探すより具体的な絵になる。
