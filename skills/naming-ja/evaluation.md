# 採点と比較

採点の前に、[anti-patterns.md](anti-patterns.md) の危険信号チェックリストを通す。2つ以上当てはまった候補は採点しない。

## 採点表

各項目を1〜5で付け、重みを掛ける。

| 区分 | 項目 | 見ること | 重み |
|---|---|---|---|
| 核 | 比喩の強さ | 具体的な絵が浮かぶか。機能とつながるか | ×3 |
| 核 | 覚えやすさ | 一度聞いて翌日も覚えているか | ×3 |
| 核 | 由来 | 15秒の由来があり「うまいね」と言われるか | ×2 |
| 核 | 区別 | 競合と混同されないか | ×2 |
| 実用 | 電話テスト | 聞いて表記を迷わず検索できるか。読みが1つか | ×2 |
| 実用 | 長さ | 2〜5モーラが目安。長いと減点 | ×1 |
| 実用 | 響き | 音の印象が商品の性格と合うか | ×1 |
| 実用 | 空き | 必要な場所（ドメイン・商標・SNS）が空いているか | ×1 |
| 状況 | 並べたときの相性 | 個人名や既存ブランドと並べて違和感がないか | ×1 |
| 状況 | 表記の安定 | 表記ゆれ・ローマ字の割れが少ないか | ×1 |
| 状況 | 長持ち | 5〜10年後も古びないか（流行語に頼っていないか） | ×1 |
| 状況 | 検索のしやすさ | 名前で検索して自分が見つかるか。一般語に埋もれないか | ×2 |
| 状況 | 混み具合 | 同業・隣接業種で同じ名前を使う組織がどれだけあるか（5=なし、1=多数） | ×1 |

満点は110。75を超えれば強い候補、85を超えれば非常に強い。70を超える候補がなければ、比喩の領域から考え直す。

```text
名前: ______（読み: ______ / ローマ字: ______）
核:   比喩 _×3  覚えやすさ _×3  由来 _×2  区別 _×2
実用: 電話 _×2  長さ _×1  響き _×1  空き _×1
状況: 相性 _×1  表記 _×1  長持ち _×1  検索 _×2  混み具合 _×1
合計: ___ / 110
```

## 文脈テスト

名前は文の中で使われる。最終候補ごとに次の文に入れて、不自然さがないか確かめる。

- 紹介: 「〇〇さんに頼んでみたら？」「〇〇を始めました」
- 説明: 「〇〇は、［誰］の［何］を［どうする］サービスです」
- 日常: 「〇〇の担当から連絡がありました」「〇〇に相談しておきます」
- 告知: 「〇〇｜［1行説明］」「〇〇の無料相談はこちら」
- 口コミ: 「〇〇っていうところに頼んだら、よかったよ」— 一番大事。人に勧めるとき口に出しやすいか

## 点が近いとき

5点以内なら、次の順で決める。

1. 比喩が強い方（比喩は後から足せない）
2. 電話テストがすっきり通る方
3. 由来が気持ちいい方（何千回も話すことになる）
4. 空きがきれいな方
5. 本人が好きな方

## 24時間置く

最終候補2〜3個を、少なくとも24時間置いてから決める。
声に出す、人に言ってみて表情を見る、名刺やプロフィールに書いてみる。
日を置いても「しっくりくる」名前が残る。

## 決める前の確認

- [ ] 由来がはっきりしている
- [ ] 70点を超えている
- [ ] 電話テストを通る（言える → 打てる → 覚えている）
- [ ] 24時間置いた
- [ ] 必要な場所が空いている（未確認の項目が残っていない）
- [ ] 落とすパターンに当てはまらない
- [ ] 1000回名乗っても恥ずかしくない
- [ ] 名付けに関わっていない人が、初めて聞いて好意的だった
