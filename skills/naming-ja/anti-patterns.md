# 落とすパターン

## AI が出しがちな名前

言語モデルに名前を出させると、整っているが入れ替え可能な名前が並ぶ。

| パターン | 例 | だめな理由 |
|---|---|---|
| 意味のない造語 | ネクサジェン、ブライトリクス、〇〇リー、〇〇ファイ | 互いに区別できない。由来も絵もない |
| 類語辞典の抜き出し | アペックス、ピナクル、頂、極み | 数えきれないほど使われている |
| 分野＋飾り | クラウドガード、データシンク、業務ナビ | 何をするかは分かるが、何も残らない |
| 中身のない会社言葉 | 〇〇ソリューションズ、〇〇ラボ、〇〇総研、〇〇ホールディングス | 「会社です」以外を伝えない |
| 前向きな形容詞 | ブライトパス、ミライ〇〇、スマイル〇〇 | どの分野のどの商品でも成り立つ |

**見分け方:** 別の分野の別の商品に付け替えても「成り立つ」なら、その名前は弱い。

## 日本語で特に多い失敗

- **実態より大きく見せる**: 1人で運営しているのに「〇〇総研」「〇〇グループ」「〇〇ホールディングス」。見破られると信用を落とす
- **読めない当て字・難読漢字**: 書けば格好いいが、口頭で伝わらず検索もされない
- **英単語の羅列**: 「Smart Biz Link」のような飾り語の組み合わせ。日本の経営者層には読み方も伝わりにくい
- **流行語の前置き**: 「AI〇〇」「DX〇〇」「スマート〇〇」「次世代〇〇」
- **伝わらない駄洒落**: 説明しないと分からない掛け言葉は、説明の手間が毎回かかる
- **大手や有名サービスに似せる**: 想起は借りられるが、商標と信用の両方で危ない
- **長音・小さい字の表記ゆれ**: 「ー」の有無、「ヴ／ブ」で検索が割れる

## 組み合わせ語の罠

前に置くと飾りになりやすい語: AI、スマート、クラウド、デジタル、DX、ネクスト、プロ、スーパー、ミライ
後ろに置くと飾りになりやすい語: ナビ、ラボ、ハブ、ベース、リンク、ドットコム、ソリューションズ、ワークス

判定:
1. 前の語を隠して、後ろの語が何かを伝えるか
2. 後ろの語を隠して、前の語が何かを伝えるか
3. どちらかを類語に替えても同じくらい「良い」か → 替えられるなら具体性がない。落とす

## AI 関連サービスで避ける型

- **「AI」を名前に入れる**: 時代が過ぎると古びる。差別化にならない
- **「〇〇パイロット」「コパイロット」型**: 特定の製品の比喩として定着していて、後追いに見える
- **魔法の比喩**（マジック、魔法、錬金術）: 仕組みを隠す印象になり、業務用途の信頼と相性が悪い
- **人名を付ける**: AI がそのまま話し相手になる製品以外では、中身と合わない

## 危険信号チェックリスト

2つ以上「はい」なら落とす。

- [ ] 聞いた人が「ああ、〇〇みたいな」と別の商品を思い浮かべる
- [ ] 15秒で由来を話せない
- [ ] 一度聞いただけでは、表記が分からず検索できない
- [ ] 見た目はいいが、声に出すとぎこちない
- [ ] 響きがいいだけで、商品との比喩のつながりがない
- [ ] 別の分野の商品に付け替えても成り立つ
- [ ] 装飾（英字の大文字、記号、当て字）を外すと、ありふれた言葉になる
- [ ] 上の「AI が出しがちな名前」の表に3つ以上当てはまる
- [ ] 取引先に名乗るとき、気恥ずかしい
- [ ] 一番の長所が「ドメインが空いていたこと」
- [ ] その言葉の別の意味が、商品の約束と食い違う

## 意味の食い違い

比喩として使う意味が合っていても、別の意味が商品の約束を壊すことがある。
候補ごとに「この言葉はほかに何を意味するか」を確かめる。慣用句・俗語・方言も含める。

## 「それで？」テスト

由来を話したときの相手の反応で判断する。

- 「うまいね」→ 合格
- 「なるほど」→ 許容
- 「それで？」→ 不合格（由来が名前を支えていない）
- 「分からない」→ 不合格（参照が遠すぎる）
- 「それ、もうあるよね」→ 不合格（先に使われている）
